## HB-RF-ETH Home Assistant 0.3.1

This release adds remote gateway setup and improves configuration and action handling.

### Changes

- Remote gateway setup accepts IPv4, DNS names with optional ports, and bare IPv6 addresses, including addresses configured for Tailscale.
- Reconfiguring an existing gateway preserves its device and entity IDs when its address changes. A different serial number blocks reconfiguration for entries identified by serial.
- Password fields are masked. Leave the reconfiguration password field blank to keep the saved password.
- Gateway actions require exactly one matching target. An explicit invalid target aborts the action.
- Timeouts, invalid API responses and rejected tokens are handled consistently. Equal polling results skip redundant entity callbacks.
- German and English setup guides cover remote gateways, MQTT coexistence and troubleshooting. Sensor labels and action errors are translated in both languages.

### Installation

Update HB-RF-ETH in HACS, or extract the release ZIP into the existing `custom_components/hb_rf_eth` directory and restart Home Assistant. The release targets Home Assistant 2026.10.0 or newer and gateway firmware 2.4.0 or newer.
