## [0.3.0] - 2026-11-20

> ⭐ [Star the project on GitHub](https://github.com/Xerolux/hb-rf-eth-hass/stargazers)

### ⚠️ Upgrade notes

- **Restart Home Assistant after updating.** Existing hub configuration and the **Services only** option are retained. Firmware 2.4.0 or newer is required for the REST update features.

### ✨ Improvements

- **Discover and reconfigure the gateway in Home Assistant.** mDNS discovery, reauthentication and native reconfiguration are available.
- **Use Services only alongside MQTT Discovery.** Backup, restore, log download, restart and update checks remain available without duplicate REST entities.
- **Install the stable release through Home Assistant Marketplace or HACS.** The README also documents manual installation from the release ZIP.

### 🐛 Bugfixes

- **Update entities explain when a search did not finish successfully.** Pending, failed and skipped searches no longer reuse the installed version as the latest result.
